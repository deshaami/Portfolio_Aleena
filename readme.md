## 🚀 Featured Research

### 🧭 Adaptive Indoor Robot Navigation

**Adaptive RRT*-Based Indoor Robot Navigation Using Sensor Fusion and Predictive Obstacle Avoidance**

A research framework combining:

* RRT* path planning
* Sensor-fusion-based risk estimation
* Machine-learning-based planner selection
* Predictive Obstacle Avoidance Mechanism (POAM)
* Adaptive replanning
* Path smoothing and robot motion control

The work investigates how autonomous robots can dynamically adapt their navigation strategy according to environmental conditions.

> 📄 **Accepted for ICNGIS 2026**
